Application Python en console qui permet de gerer une liste de taches.Elle propose un menu simple avec les fonctionnalites suivantes:
   . Ajouter une tache
   . Afficher toutes les taches
   . Rechercher une tache par mot-clé
   . Quitter l'application

Les etpaes du projet fil rouge(DS):
Apres la creaction d'un projet python qui nous permet d'ajouter,afficher et rechercher les taches et l'enregitrer dans le dossier du projet,j'ai fais les etapes suivantes:
1) c ~/(nom du chemain):c'est le chemain ou se trouve le dossier qu'on va travailler avec.
2) pwd: pour verifier le dossier courant
3) git init:pour transformer le dossier existant en depot git
4) git status: pour me montrer ce qui a change dans mon projet et ce qui est pret a etre sauvegarde
5) git add nom de fichier.type de fichier:prepare les changement pour le prochain commit
6) git status:pour verifier qu'on a ajouter le fichier qu'on va travailler avec
7)git commit -m "message":pour ecrire le message direct dans le commande,sans ouvrir l'editeur.Transforme la zone de staging en histourique Git 
8) la creation du new repository sur GitHub
9) coppilage d'URL
10) git remote add origin URL:relie mon depot local(Git bash) a un depot distant(GitHub)
11) git remote -v:la verification du l'URL apres avoir ajoute origin 
12) git branch -M main:pour avoir une branche principale nommee main
13) changement dans le code du projet et puis l'enregistrer
14) git status:pour verifier qu'il y a un changement dans le programme
15) git add nom du fichier.type de fichier:prepare les changement pour le prochain commit
16) git commit -m "message":pour ecrire le message direct dans le commande,sans ouvrir l'editeur.Transforme la zone de staging en histourique Git 
17) git push:publier les commits locaux vers le depot distant
18) verification de l'actualisation du page GitHub pour confirmer le sauvgarde du mise a jour
